Resumo: O Trabalho para casa da primeira aula teórico-prática consiste na resolução do nível 10 do "blocky games" (plataforma online de jogos que ensinam a lógica da programação)", que se trata de uma programação simples tipo "scratch", mais intuitiva (figura 1). Esse desafio consiste em programar o caminho para chegar de um ponto A até um ponto B. Além disso, foi pedido um desenho de um barco à vela como se pode ver abaixo (figura 2) utilizando a função "turtle" do mesmo website.
